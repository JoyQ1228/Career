# 求职下一步 MVP

面向在校大学生的实习与校招求职原型，覆盖岗位筛选、申请准备和投递跟进。

## 原型范围

- 同时支持实习和校招岗位
- 根据求职目标切换到岗时间、实习周期或毕业届别筛选
- 根据岗位类型提供条件自查和申请准备清单
- 管理待准备、待投递、已投递、笔试/面试、已录用和已结束状态

## 本地运行

直接打开 `index.html` 即可。数据保存在当前浏览器的本地存储中，不会上传简历或发送真实申请。

## GitHub Pages

将仓库发布为 GitHub Pages 后，访问地址通常为：
