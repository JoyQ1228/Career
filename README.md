# 职汇 MVP

面向在校大学生的信息聚合与申请管理原型，覆盖岗位汇总、分类筛选、申请准备和进度跟进。

## 原型范围

- 从企业官方招聘渠道、高校就业网和政府公共招聘平台采集岗位，统一字段、去重并人工复核
- 将“实习”和“校招”设为两个独立入口，分别显示到岗条件或毕业届别筛选
- 每个岗位保留信息来源、最近核验时间、投递渠道和官方原岗位入口
- 用户将岗位加入申请清单，完成条件自查和材料准备后前往官方渠道投递
- 平台不代投；用户投递完成后回到产品记录日期、渠道、待办和后续进展
- 管理待准备、待投递、已投递、笔试/面试、已录用和已结束状态

## 本地运行

直接打开 `index.html` 即可。数据保存在当前浏览器的本地存储中，不会上传简历或发送真实申请。
